# Coupling Summary Evidence

Keep compact, decision-relevant evidence for each closed iteration under `iterXXX/`.

The approved kickoff package defines required current evidence. Keep raw, large, reproducible, or
intermediate outputs outside Git in the authorized scratch root. Record their canonical paths,
sizes, hashes, provenance, and retention limitations in the iteration report.

Closeout validation checks current required artifacts. Paths proposed only for a future iteration
need not exist.

Do not introduce an iteration-specific schema as a workflow-wide standard without updating the
workflow, templates, validators, and existing consumers together.
